2. Map data inside the application
----------------------------------

Two files derived from OpenStreetMap are compiled into the application and are read every
time the map draws, so they are distributed with it under the Open Database License 1.0:

  rail-overview.geo.json     the railway network at low zoom, extracted from the label and
                             road layers of a Protomaps build of OpenStreetMap.
  admin-labels.geo.json      region and province label points, extracted from OpenStreetMap
                             through the Overpass API (admin_level 4 and 6 within Italy).

  Copyright (c) OpenStreetMap contributors,
  https://www.openstreetmap.org/copyright
  Licence: LICENSE-ODbL-1.0.txt

The map displays "© OpenStreetMap contributors" in its credit line.

4. Map style, glyphs and sprites
--------------------------------

The map style is written for this application against the Protomaps vector-tile schema. Its
visual design follows OpenFreeMap's Liberty style, itself derived from OSM Liberty and OSM
Bright: style code BSD-3, design CC BY 4.0, OSM Bright design CC BY 3.0. Copyright (c)
Zsolt Ero, Mapbox, OpenMapTiles and the respective contributors. The style is a port of that
look, not a copy of the upstream style document.

  https://github.com/hyperknot/openfreemap-styles
  https://github.com/maputnik/osm-liberty
  https://creativecommons.org/licenses/by/4.0/

The label glyphs in resources/map/fonts are derived from Noto Sans Regular and Medium:
Copyright 2022 The Noto Project Authors, SIL Open Font License 1.1. The licence travels
beside them as resources/map/fonts/OFL.txt.

The sprite sheet in resources/map/sprites is rendered from Lucide icons, ISC, as listed in
section 1.

7. Keeping this file true
-------------------------

Replacing a dataset changes NOTICE-places.txt or NOTICE-routing.txt, not this file. Adding,
removing or upgrading a bundled library, a renderer dependency or a derived map file
changes this file in the same change.
